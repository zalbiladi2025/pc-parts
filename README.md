# دليل القطع — مرجع قطع الحاسوب الداخلية

موقع مرجعي (HTML / CSS / JavaScript فقط، بدون مكتبات) يشرح ثماني قطع أساسية داخل الحاسوب بطريقة جذابة: وظيفتها، مواصفاتها التي تُقرأ عند الشراء، معلومة "هل تعلم؟" لكل قطعة، ونصيحة توافق مرتبطة بها.

هذا الموقع مصمم ليكون **مرجعاً وإجابة** لتمرين **"ورشة التجميع"** (اللعبة التفاعلية السابقة) — قسم "ملخّص قواعد التوافق الخمس" في نهاية الصفحة يغطي بالضبط النقاط الخمس التي تُختبر في أسئلة المرحلة الأولى من اللعبة.

## الملفات

```
pc-components-guide/
├── index.html   # الهيكل: شريط تنقّل، بطل بمخطط تشريحي تفاعلي، أقسام القطع، ملخص القواعد
├── style.css    # نفس الهوية البصرية (PCB) المستخدمة في لعبة ورشة التجميع
├── script.js    # بيانات القطع والمواصفات، وبناء الأقسام وتمييز التنقل أثناء التمرير
└── README.md
```

## المحتوى

يغطي الموقع القطع الثماني التالية، كل قطعة بقسم كامل يحتوي على وصف، بطاقات مواصفات، معلومة مثيرة، ونصيحة توافق:

1. المعالج (CPU)
2. اللوحة الأم (Motherboard)
3. الذاكرة العشوائية (RAM)
4. كرت الشاشة (GPU)
5. وحدات التخزين (Storage)
6. وحدة التغذية الكهربائية (PSU)
7. نظام التبريد (Cooling)
8. صندوق الجهاز (Case)

في أعلى الصفحة مخطط تشريحي تفاعلي (Hotspot board) يمكن الضغط على أي قطعة فيه للانتقال مباشرة لشرحها.

## ربط الموقع بلعبة "ورشة التجميع"

يحتوي `index.html` على رابطين لموقع اللعبة (زر في شريط التنقل العلوي، وزر أسفل قسم "ملخّص قواعد التوافق"). **قبل النشر، استبدل** الرابط التالي في الملف برابط اللعبة الفعلي بعد رفعها على GitHub Pages:

```
https://USERNAME.github.io/pc-builder-game/
```

يُفضّل أيضاً إضافة رابط عكسي من موقع اللعبة إلى هذا المرجع، بإضافة زر مشابه في `index.html` الخاص بمشروع `pc-builder-game`.

## التشغيل محلياً

```bash
cd pc-components-guide
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## رفع المشروع على GitHub ونشره عبر GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub (مثلاً `pc-components-guide`).
2. من داخل مجلد المشروع:

   ```bash
   git init
   git add .
   git commit -m "إضافة دليل قطع الحاسوب المرجعي"
   git branch -M main
   git remote add origin https://github.com/USERNAME/pc-components-guide.git
   git push -u origin main
   ```

3. في المستودع: **Settings → Pages → Deploy from a branch** → اختر `main` والمجلد `/ (root)` → احفظ.
4. سيصبح الموقع متاحاً على:

   ```
   https://USERNAME.github.io/pc-components-guide/
   ```

## تعديل المحتوى

كل بيانات القطع موجودة في مصفوفة `components` أعلى ملف `script.js`، وكل عنصر يحتوي على: `name`, `en`, `tagline`, `desc`, `specs` (مصفوفة مواصفات), `fact`, `tip`. أضف قطعة جديدة بنفس النمط وستُبنى تلقائياً في المخطط التشريحي، شريط التنقل، وقسم الشرح دون أي تعديل إضافي على HTML أو CSS.

ملخص قواعد التوافق موجود في مصفوفة `cheatSheet` بنفس الملف.
